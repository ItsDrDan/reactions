    📗 Reference & hints

    Adapted from your green sheet. Slightly soluble compounds follow the sheet's listed exceptions in these questions.

    Reaction recipes

    Combination: A + B → AB
    Decomposition: AB → A + B
    Single displacement: A + BC → AC + B (check activity)
    Double displacement: AB + CD → AD + CB (swap ion partners, then balance charges)
    Combustion: hydrocarbon + O₂ → CO₂ + H₂O
    Neutralization: acid + base → salt + H₂O

    Four gas evolution patterns

    Carbonate + acid → H₂CO₃ → CO₂(g) + H₂O(l)
    Sulfite + acid → H₂SO₃ → SO₂(g) + H₂O(l)
    Sulfide + acid → H₂S(g)
    Ammonium + strong base → NH₄OH → NH₃(g) + H₂O(l)

    Strong acids and bases
    Strong acids: HCl, HBr, HI, HNO₃, HClO₄, H₂SO₄.
    Strong bases: LiOH, NaOH, KOH, RbOH, CsOH, Ca(OH)₂, Sr(OH)₂, Ba(OH)₂.
    Group 2 bases fully dissociate when dissolved.
    How to write complete ionic equations
    1. Predict the products and balance the molecular equation.
    2. Use the solubility chart to assign a phase to every substance.
    3. Split aqueous strong electrolytes into ions, carrying coefficients through to each ion. Keep solids, liquids, gases, and weak acids together.
    4. Cancel spectator ions that appear unchanged on both sides.
    5. Write the net ionic equation with the smallest whole-number coefficients. Check atoms and charge.
